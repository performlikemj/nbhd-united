# install fails. They are torch's CUDA runtime + its GPU kernel compiler; they serve
# the PII model, which runs in its own container. torch ITSELF builds on macOS and is
# deliberately NOT ignored here.
#
# venv_parity.sh treats a package listed here as legitimately absent, not as drift.
# Anything NOT listed here that is missing from the venv is real drift and gets reported.
#
